# Дом на Юге — сайт

Сайт https://puzzlespace.ru: калькулятор сметы, кабинет и публичные страницы.

Секреты (файл `.env`, пароли сервера и токены ботов) в этот репозиторий не входят. Образец переменных — в `.env.example`.

Запуск API описан в `README_FASTAPI.md`. Калькулятор сметы открывается по адресу `/estimate`.
