# Сводное КП: что именно понял и как

## Исходные данные

- Есть **согласованные** спецификации (kp_approved = true), например: S01, S02, S03, S04, S05 (5 штук).
- У каждой спецификации — список позиций: наименование, кол-во, ед., цена, сумма.

## Правило объединения

**Объединяем только те спецификации, у которых позиции совпадают на 100%.**

То есть у двух (или нескольких) спецификаций должны быть:
- один и тот же набор позиций (те же наименования, при необходимости та же привязка к номенклатуре/шаблону);
- одинаковое количество по каждой позиции;
- одинаковые цены по каждой позиции.

Тогда такие спецификации считаются **одной группой** и дают **одно сводное КП**.

## Пример

- **S01, S03, S04** — состав позиций полностью одинаковый → одна группа из **3 домов**.
- **S02, S05** — состав позиций полностью одинаковый между собой, но отличается от S01/S03/S04 → другая группа из **2 домов**.

В итоге получается **два** сводных КП (две таблицы или два блока):

1. **Сводное КП по группе 1**  
   Спецификации: A00001-P01-S01, A00001-P01-S03, A00001-P01-S04 (**3 дома**).  
   Для каждой позиции: кол-во на 1 дом, цена, сумма на 1 дом, **Количество домов = 3**, **Кол-во всего = кол-во × 3**, **Сумма всего = сумма × 3**.

2. **Сводное КП по группе 2**  
   Спецификации: A00001-P01-S02, A00001-P01-S05 (**2 дома**).  
   Для каждой позиции: кол-во на 1 дом, цена, сумма на 1 дом, **Количество домов = 2**, **Кол-во всего = кол-во × 2**, **Сумма всего = сумма × 2**.

## Как технически определить «100% одинаковые позиции»

Для каждой согласованной спецификации строим **отпечаток** (fingerprint) набора позиций, например:

- отсортированный список пар: `(item_name, quantity, unit, price)` или  
  `(nomenclature_item_id или template_id, quantity, price)` — если опираемся на справочники;
- либо хеш от этого списка.

Спецификации с **одинаковым отпечатком** считаем одной группой и объединяем в одно сводное КП.

## Итог

- **Группа** = множество согласованных спецификаций с идентичным набором позиций (наименование + кол-во + ед. + цена).
- **Одно сводное КП** = одна такая группа: перечень спецификаций по номерам (S01, S03, S04), количество домов в группе, таблица позиций с кол-вом на 1 дом, количеством домов, кол-во всего и сумма всего.
- Согласованных спецификаций может быть сколько угодно; количество **сводных КП** равно количеству **разных** по составу групп.
