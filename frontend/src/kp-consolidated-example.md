**Если в сводку входят спецификации с разным составом** (например, S01 и S02 совпадают, S03 — другая комплектация):

**Спецификации:** A00001-P01-S01, A00001-P01-S02 (2 шт.), A00001-P01-S03 (1 шт.)

Тогда позиции, которые есть только в S01 и S02, идут с «Количество домов» = 2; позиции только из S03 — с «Количество домов» = 1; позиции, общие для всех трёх, — с «Количество домов» = 3.

| … | … | … | … | … | … | … | … | … |

**Формулы:**
- **Количество домов** = число согласованных спецификаций, в которых есть эта позиция (с тем же наименованием/привязкой).
- **Кол-во всего** = Кол-во (на 1 дом) × Количество домов.
- **Сумма всего** = Сумма (на 1 дом) × Количество домов.

Спецификации в шапке или в подвале таблицы перечисляются по номерам: A00001-P01-S01, A00001-P01-S02 и т.д.
